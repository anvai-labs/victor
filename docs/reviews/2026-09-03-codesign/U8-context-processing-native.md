# U8 — Context, processing, native & Rust

120 Python modules / 40,103 LOC + 13.4k LOC Rust workspace / 726 churn commits (12m). Reviewer: parallel unit review, 2026-09-03.

## Overview
The native/Python split is genuinely roofline-aware for CPU-bound work (tokenize, similarity, pattern-match, chunking) and the fallback discipline is real — but **semantic parity has drifted in exactly the two functions that guard the LLM context budget** (token counting, context fitting), and a 4th "protocol" accelerator stack plus a dead `victor/context/manager.py` multiply maintenance cost. GIL handling and FFI data movement are good on similarity (batch, `py.detach`), absent everywhere else.

## Co-design opportunities
1. One-crossing slot fitting: `fit_context` costs N FFI crossings to build `MessageSlot` pyobjects + 1 to fit. Accept parallel lists (roles, token_counts, priorities, recencies) or build slots inside Rust.
2. Zero-copy embeddings: similarity takes `Vec<Vec<f32>>` (full copy per call, similarity.rs:128) while the NumPy fallback wins benchmarks partly because it's zero-copy. Enable PyO3 buffer-protocol support; persistent `EmbeddingIndex` pyclass as the only batch path.
3. Content-hash memoized token counts: stored messages are immutable; `hashing.rs` already provides xxh3 signatures. Cache counts by signature in the conversation store/assembler instead of re-tokenizing the whole history every pass.
4. Release the GIL on batch entry points (tokenizer.rs:274, context_fitter.rs, chunking.rs) using the pattern proven in similarity.rs.
5. Parity harness as CI law: generated test matrix asserting native == fallback for every flat shim (strategies × token estimators × streaming flush). F1/F2/F7 are precisely the drift class it would have caught.
6. Ship the BPE ranks: one lazy `BpeTokenizer("cl100k", ranks)` at startup unifies exact counting across both backends.

## Keep intact
- `victor/processing/native/_base.py:30-65` — single `_NATIVE_AVAILABLE` flag, one-time install hint, `_PYTHON_PREFERRED_OPERATIONS` benchmark-aware dispatch (NumPy wins batch similarity); the honest single source of truth.
- `pattern_match.rs:34-68` — bounded (512-entry) Arc-shared Aho-Corasick automaton cache keyed by flags+patterns; exactly the right compiled-pattern amortization.
- `victor/native/observability.py` adaptive EWMA dispatch (69-174, consumed by accelerator.py:460-498): per-backend EWMA with `update_ewma=False` for non-attributable observers — a genuinely closed measure→dispatch loop.
- API-reported usage written back via `store.py:1208 update_message_token_count` — self-corrects estimator drift after each real LLM call; F2 is tolerable only because this exists.
- `project_context.py` signature caching keyed by (path, mtime, size) with force_reload — correct incremental recompute for the I/O-bound side of context assembly.
