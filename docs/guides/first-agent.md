# Your first agent

The maintained Python tutorial is [Your First Agent in 5 Minutes](../getting-started/first-agent.md).
It uses `await Agent.create(...)`, manages the agent with an async context manager,
and demonstrates both task execution and streaming.

For additional configuration, see the [Python API reference](../reference/api/python-api.md),
[tool catalog](../reference/tools/catalog.md), and [vertical reference](../reference/verticals/index.md).
The previous examples on this page used an obsolete constructor and chat API;
they remain available in [repository history](https://github.com/anvai-labs/victor/commits/develop/docs/guides/first-agent.md).
